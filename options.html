🖥️ Local LM Studio Configuration

Start the server in LM Studio: open Settings → Local Model API and toggle the top option on (default port 1234). LM Studio shows the base URL as http://localhost:1234/v1 — you can paste that here or just http://localhost:1234; the /v1 suffix is stripped automatically.
Leave blank unless you turned on Require Authentication in LM Studio's Server Settings and created a token via Manage Tokens (LM Studio 0.4.0+). Sent as a Bearer token for /api/v1/chat and /api/v1/models.

🔑 API Key Configuration

🔄 Multiple Gemini API Keys

Add multiple API keys from different Google Cloud projects. The extension will automatically rotate between them when rate limits are reached.

Testing sends one API request per key and may count toward each key's quota.

🧠 Gemini Model

Choose which Gemini model to use. New Google AI Studio API keys can no longer access the 2.5 models (they return a 404 "no longer available to new users"), so pick a current model such as gemini-3.5-flash-lite.

Pick a model from the dropdown. Or click "Load Available Models" to fetch the models your API key can actually use.

⚙️ General Settings

How many emails to analyze at once during a batch (1–20). Default 5. Higher is faster but fires more API requests at the same time.

ℹ️ How AI Sorting Works

AutoSort+ uses AI to analyze your emails and automatically sort them into categories/folders based on their content. The AI will:

  • Read and understand email content
  • Identify key topics and themes
  • Match emails to appropriate categories/folders
  • Learn from your manual corrections to improve accuracy
